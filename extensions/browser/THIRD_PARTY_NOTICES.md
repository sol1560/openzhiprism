# Source references

The current-conversation API approach and ChatGPT active-branch traversal were adapted from Pierre Munhoz's ChatGPT & Claude Conversation Exporter:
https://github.com/p-munhoz/chatgpt-claude-exporter
Reference commit: 1c296770eab0420f230d789def423133757cc2f0 (2026-08-30).

DOM selectors were reviewed against ExportChat by Ajit Khandekar:
https://github.com/Ajit-Khandekar/exportchat
Reference Claude file blob: 789071ea2148a53b04a81f2b8a7c0eca1c97fd9f.
Its alternating-message concatenation is not used.

The extraction adapters, one-click UI, OAuth client and ZhiPrism integration in this package are maintained in this repository. No upstream analytics, exporters or remote scripts are bundled.
