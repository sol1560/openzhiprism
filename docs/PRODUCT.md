# 知棱 ZhiPrism · 产品说明计划书

> 知乎黑客松 2026 校园新锐季 · 知识炼金场（社区 × 学习）· 作者：Sol

## 项目概述

知棱从你与 AI 助手的日常对话里发现兴趣，每天为你整理一份知乎内容 Feed；在你只听一种声音的话题上补充另一方；并把阅读接到「核对依据 → 想清楚 → 留下判断」的学习闭环里。使用的知乎能力：知乎搜索、知乎热榜、直答、用户关注。

## 一、创作思路

一个大三学生在 Claude 里问「不考研会不会找不到好工作」，接着让 AI「帮我列一下考研的好处」。这样的对话每天都在发生，它暴露了三件事：

1. **最真实的求知信号发生在站外。** 一个人在 AI 对话里说的话，比他在任何平台上的点击都更接近「我正在想弄清楚什么」，但这份信号从未进入过知识社区。
2. **AI 会顺着你说。** 要考研的好处就给好处，要先工作的理由就给理由。对正在做人生选择的学生来说，这是一个由 AI 帮忙搭建的茧房。而知乎最有价值的，恰恰是那些有分歧、带条件的真实经验。
3. **读得多不等于想清楚。** 读了十篇回答，留下的只是浏览记录，没有变成「我基于哪些依据、在什么条件下、形成了什么判断」。

知棱不做新的内容平台，而是给知乎做一层面向 AI 对话场景的发现与学习层。一个话题在用户身上走过五步，每一步都由知乎内容驱动：

| 阶段 | 用户看到的 | 知乎提供的 |
|---|---|---|
| 看见 | 对话 → 兴趣画像 → 每日 Feed：摘要、来源、推荐理由 | 搜索接口的高赞回答与文章，热榜的轻松内容 |
| 理解 | 「换个角度看」：另一方的高赞回答与中立分析 | 同一问题下不同立场的回答 |
| 核对 | 「看分歧与依据」：逐字引文、成立条件、反例与边界 | 回答正文是唯一的证据来源 |
| 思辨 | 三轮「帮我想清楚」：处境 → 依据 → 边界 | 引文被用户拿来支持或限定自己的判断 |
| 沉淀 | 「我的判断」：版本化、可导出、跟踪新材料 | 判断绑定知乎原文链接 |

这正是「知识炼金场」的题意：让知识不只是被看见，也能被理解、吸收和再次创造。

三条原则：知乎是内容与结论的来源，知棱只做摘要、引导与核对，原文永远在知乎；AI 只做翻译与核对，不替用户下结论，每一句归纳都绑定逐字引文，判断必须由用户亲自确认；隐私先于能力，对话进入模型前先脱敏，原文不转交任何第三方。

## 二、与知乎社区的契合与场景价值

### 四个场景

**聊完就有的今日阅读。** 用户在 Claude 里说「把这段对话交给知棱」，助手把当前对话整理后交给知棱，脱敏、提取兴趣、更新画像。之后用户问「今天有什么值得看的」，Claude 直接呈现一张知棱 Feed 卡片：每条含摘要、赞同数、推荐理由「因为你最近在聊「考研 vs 就业」」，点击跳转知乎原文。

**只听一种声音的时候。** 画像里「考研 vs 就业」是争议话题，用户立场偏向「先考研」，接触到的同向内容超过六成，于是 Feed 里出现一张带棱镜边框的「换个角度看」：核心问题「应届生应该先考研还是先工作？」、「先工作」一方的两条高赞回答、一段基于引文的中立分析，并明确标注这是刻意补充的不同视角。

**做决定之前。** 从任何一张卡片点「看分歧与依据」，知棱把相关知乎回答整理成逐字引文、分歧维度、共识、成立条件与反例。用户可以开始一次最多三轮的短程思辨：先说处境，再被追问「你会用哪条原文支持这个判断」，最后被追问「什么条件变化时你会重新考虑」。结束后得到一份只包含自己原话的草稿，确认后保存为「我的判断」，可以修改留版本、导出、继续关注并在有新材料时收到提醒。

**路上也能继续。** 语音向导「小棱」先读今天的简报，再逐条引导；讲完一张卡主动问「这个话题还有另一方的看法，要听吗」。小棱只讲 Feed 里真实存在的内容。

### 对知乎的价值

1. **流量回流站内。** 知棱只展示摘要；每条推荐、每条引文都直达知乎，打开即记为已读。知棱越有用，用户去知乎读原文的次数越多。
2. **知乎内容进入 AI 对话场景。** 知乎内容出现在 Claude、ChatGPT、Claude Code、Codex、Cursor 里，成为知乎在 AI 助手内的站外触点。
3. **站内拿不到的意图信号。** 话题级画像（话题、权重、用户提出过的问题、立场倾向、是否争议）描述的是「用户正在想弄清楚什么」，而不是「用户点过什么」。
4. **高质量的内容反馈。** 用户对具体回答的「有帮助 / 已知道 / 不相关 / 归纳有误」，以及引文被采纳进用户判断的次数，都绑定到具体内容，比点击更可靠。
5. **放大知乎独有的资产。** 通用搜索与 AI 问答给的是答案，知乎给的是「在什么条件下成立的经验」。把成立条件、反例与共识结构化，只有在知乎内容上才做得出来。
6. **与社区秩序天然兼容。** 只读不写：不发布、不评论、不点赞；接口调用前先读额度，结果按检索词与内容缓存并跨用户复用。

### 对学生与职场新人的价值

不用关注、订阅、搜索，对话本身就是信号；每条推荐都能解释；在只听一种声音的地方看到另一方，在准备下结论的地方被追问依据；阅读留下的是自己确认的判断，而不是浏览记录。

## 三、核心功能

| 功能 | 说明 |
|---|---|
| 对话兴趣采集 | 在 AI 助手里说一句「把这段对话交给知棱」，或用浏览器插件一键导入、网页粘贴与上传聊天记录。进入模型前隐去手机号、身份证、邮箱、地址、金额等，只提取话题、关键词、问题、立场与争议标记 |
| 兴趣画像 | 按「提及次数 × 讨论深度」累积，14 天半衰期衰减，随对话变化；同源话题自动合并 |
| 今日 Feed | 每天 12 条主内容按画像权重与阅读历史分配，每 4 条插 1 条热榜轻松内容；两三句摘要加推荐理由；每日简报；一句话即可改写摘要、追加检索、多推少推某个话题 |
| 换个角度看 | 识别争议话题，分别检索正方、反方、中立回答；同向内容超过六成时插入另一方，并明确标注 |
| 看分歧与依据 | 把知乎回答整理成逐字引文、分歧维度、共识、成立条件、反例与未解问题；模型的每句归纳都必须对应原文，对不上就不展示 |
| 帮我想清楚 · 我的判断 | 最多三轮、每轮一个问题的短程思辨；判断由用户确认后保存，修改留版本，可导出，可继续关注新材料 |
| 语音向导小棱 | 先汇报再逐条引导，讲完主动递上另一方；标记已读、打开原文、保存判断都先确认 |
| 连接 AI | 支持 Claude、ChatGPT、Claude Code、Codex、Cursor 与自定义 Agent 六种接入方式，登录授权一次即可；在支持的助手里，Feed、画像、视角与证据以交互卡片呈现 |

首页内嵌一个可操作的示例沙盒：三个虚构人物，可查看示例对话、拖动兴趣权重看推荐变化、切换「换个角度看」的观点、试一遍「核对依据 → 三步想清楚 → 确认判断」，无需登录。
